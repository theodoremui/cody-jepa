# Documentation

This folder is intentionally minimal while the next research direction is being chosen.
The previous active method documents and tutorial track have been removed so the repo does
not point readers toward a study that is no longer the baseline.

Use [../results/README.md](../results/README.md) for the current summary of checked-in
aggregate outputs. New documentation should be added here only after the next research
question, method, and claim boundaries are clear.

Current boundaries:

- No active study proposal is documented here.
- No tutorial curriculum is currently maintained.
- Private data, checkpoints, feature exports, and participant-level outputs stay outside
  Git.
- Result summaries should describe checked-in aggregate evidence, not intended future
  claims.
