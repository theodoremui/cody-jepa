# Results

This folder holds compact, non-identifying research outputs that are safe to
track in Git. It is for aggregate diagnostics, figures, and paper-ready
summaries, not raw data or participant-level records.

Use this folder only for outputs that can be regenerated from the project
scripts and reviewed for privacy. Private checkpoints, feature arrays,
query-level outputs, participant tables, raw datasets, and local paths belong in
ignored output directories.

When adding a result, keep the file small, label the protocol that produced it,
and make sure a reader can trace it back to the documented analysis workflow.
